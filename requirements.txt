# =============================================================================
# Dayforce TAFW -> Databricks Ingestion Service
# =============================================================================
# Architecture (post-meeting revision):
#   - Runs as a Databricks Job (Python task / notebook), NOT Azure Functions.
#   - Staging "system of record" is a Delta table in Databricks, NOT PostgreSQL.
#   - Pulls TAFW data per-employee from the Dayforce REST API, paces requests
#     to stay under ~100 calls/min, builds a deterministic per-record hash
#     (EmployeeXRefCode + PTO date + approval/type code + hours requested),
#     then MERGEs the reconciled rows into the Databricks staging table.
#
# Python: 3.11+ (matches Databricks Runtime 15.x LTS).
# hashlib / hmac / json / datetime are in the standard library - no package needed.
#
# Install:  pip install -r requirements.txt
# =============================================================================
